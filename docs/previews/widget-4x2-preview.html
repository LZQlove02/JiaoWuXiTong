4×2 今日课程 · 方案 B（定稿版）

最多 3 行、不做超额提示、进行中不做选中效果；行数 1–3 行时都贴顶部，「下一节」始终钉在卡片底部。

壁纸
同样的结构换三种卡片底；状态只有「待上 / 进行中 / 已结束」三种文字

这一版的结构规则

  • 最多 3 行：一天超过 3 门也只显示前 3 门，不做「还有 N 门」占位。
  • 行数跟随实际课数：1 门 1 行、2 门 2 行、3 门 3 行，都贴着主体顶部。
  • 「下一节」固定底部：主体区撑满剩余高度，行少时下方留白，footer 位置不动。
  • 不做选中效果：进行中不加底色、不加竖条，只靠右侧状态文字（进行中 用强调色文字，其余灰色）。

行内结构

  • 左：时间 42dp，10.5sp，等宽数字。
  • 中：课名 · 教室 单行，12sp / 9.5sp；截断先截教室，课名最后才省。
  • 右：状态 34dp，9sp，右对齐。
  • 行高 21dp，三行 63dp；主体可用约 74dp，三行也放得下并留余量。

真机约束

  • 卡片实测 300×140dp（900×420px @3x）：内边距 20 + 头部 22 + 底部 18，主体剩约 74dp。
  • RemoteViews 不能 addView：仍用 3 个固定槽位，行数不足就把后几行 GONE；footer 靠外层 layout_weight 撑到底部。
  • 状态判定用 ClassItem.startTime / endTime 与当前时间比较，无需新增字段。
