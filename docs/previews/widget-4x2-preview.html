同样的结构换三种卡片底；课程行只有三段：时间 / 课名 / 教室

这一版的结构规则

  • 最多 3 行：一天超过 3 门也只显示前 3 门，不做「还有 N 门」占位。
  • 行数跟随实际课数：1 门 1 行、2 门 2 行、3 门 3 行，都贴着主体顶部。
  • 「下一节」固定底部：主体区撑满剩余高度，行少时下方留白，footer 位置不动。
  • 不显示课程状态：2026-11-21 起去掉行尾「待上 / 进行中 / 已结束」，也不做进行中高亮（不加底色、不加竖条）。

行内结构

  • 左：时间 46dp，13sp，等宽数字。
  • 中：课名 weight=1，16sp 单行，超出省略。
  • 右：教室 maxWidth=100dp，13sp，marginStart=6dp，放不下才省略。
  • 行高约 21.5dp、行距 2dp，三行约 68dp；真机主体可用约 98dp，三行也放得下。

真机约束

  • 真机实测 338×171dp（930×470px @2.75x）：内边距 20 + 头部约 25 + 底部约 24，主体剩约 98dp。
  • RemoteViews 不能 addView：仍用 3 个固定槽位，行数不足就把后几行 GONE；footer 靠外层 layout_weight 撑到底部。
  • resizeMode=none：组件固定 4×2，不会被用户拖成更小尺寸，三行版面不会因此被裁。
