## 0. 摘要

首次打开 App 时，在登录页之前显示全屏免责声明；用户必须点「同意并继续」才能进入应用，点「不同意，退出」直接退出。同意状态按**声明版本号**记录，只有声明文案修订（版本号 +1）时才重新弹出。未同意前不恢复登录态、不发网络请求、不写桌面小组件。

## 1. 背景与目标

App 是个人开发的第三方客户端，直连学校教务系统。需要在使用前明确告知：非官方、数据来源与归属、账号不落地、风险自担、合规使用。

目标：

1. 首次启动必须阅读并同意，不能绕过（含深链启动）。
2. 同意后不再打扰；声明内容更新时可重新告知。
3. 未同意前不产生任何登录恢复、网络请求与组件写入。
4. 用户可在「设置 → 关于」下随时重读声明。

## 2. 范围与非目标

**范围内**

- 首启全屏门禁、同意 / 不同意两个出口
- 按声明版本记忆同意状态
- 设置页「免责声明」只读重读入口
- 单元测试与文档

**非目标**

- 不做账号级同意（未登录也要先同意）
- 不做多语言
- 不做隐私政策 / 用户协议等其它法务文本
- 不接后端记录同意行为（无后端）

## 3. 交互与流程

### 3.1 启动

```
启动
├─ 已同意（本地记录 == 当前声明版本）→ 现有流程：恢复会话 → 启动页 → 首页 / 登录页
└─ 未同意 → 免责声明（全屏）
   ├─ 同意并继续 → 写记录 → 恢复会话 → 首页（有会话）/ 登录页（无会话）
   └─ 不同意，退出 → 原生：退出 App；Web 预览：显示「已退出，请关闭此页面」
```

- 未同意时不调用 `auth.bootstrap()`，因此不会复用 Cookie、不会请求课表。
- 未同意时不注册原生监听、不同步小组件；Android 返回键走系统默认（关闭 Activity）。
- 深链启动同样先过门禁；同意并完成会话恢复后再处理启动 URL。

### 3.2 重读

「设置 → 通用 → 免责声明」打开只读版本，仅一个「关闭」按钮；Android 返回键关闭。只读模式不回写同意状态。

### 3.3 重弹规则

- localStorage 键：`lzpu.disclaimer.accepted`，值为声明版本号（如 `1`）。
- 代码常量 `DISCLAIMER_VERSION = '1'`；文案修订时同时改常量与文档，老用户下次启动重弹。
- 「清除缓存」「退出登录」不清除该键（现有清缓存只删 `lzpu.cache` / `lzpu.portal.v1.` 前缀）。
- 卸载重装视为首次。

## 4. 条款文案（v1）

1. **非官方应用**：本应用为个人开发的第三方客户端，与学校及教务系统运营方无隶属关系，不对外分发、不商业化。
2. **数据来源**：课表、成绩等数据来自学校教务系统，仅限本人账号只读使用；不采集、不上传他人数据。
3. **账号安全**：登录在学校统一认证页面完成，本应用不保存账号密码；本机仅保存加密会话，可在退出登录时删除。
4. **使用风险**：接口可能随时变更或失效，数据仅供参考，以学校教务系统为准；使用本应用产生的后果由使用者自行承担。
5. **合规使用**：请遵守学校网络与信息管理规定，不得用于爬取、传播他人数据或商业用途。
6. **声明更新**：本声明修订后将于下次启动重新提示。

## 5. 技术设计

| 单元 | 职责 | 依赖 |
|---|---|---|
| `src/utils/disclaimer.js` | 声明版本常量、读写同意状态；存储异常降级为未同意 | localStorage |
| `src/components/DisclaimerGate.vue` | 全屏声明；`gate` 模式出「同意/不同意」，`reader` 模式出「关闭」 | 无 |
| `src/App.vue` | 门禁分支；同意后才 `bootstrap()` 与原生初始化 | auth store、Capacitor |
| `src/main.js` | 已同意才启动会话恢复 | disclaimer util |
| `src/views/Settings.vue` | 「免责声明」入口与只读浮层；注册返回键关闭 | ui store、DisclaimerGate |

关键点：

- `App.vue` 用 `consented` ref 控制分支，避免路由闪烁。
- 原生初始化抽成 `setupNative()`，用 `nativeReady` 防重复；同意前不执行。
- 同意后 `await router.isReady()`，有会话且当前在登录页时 `replace('/')`。
- 组件样式沿用 `theme.css` 变量与 `base.css` 的卡片、按钮观感；内容区可滚动，限宽 520px，适配安全区与横屏。

## 6. 边界与异常

| 场景 | 行为 |
|---|---|
| localStorage 读异常 | 视为未同意 |
| localStorage 写异常 | 仍进入 App（本次会话有效），下次启动再弹 |
| 同意时会话恢复失败 | 进入登录页，不弹错误（与现有冷启动一致） |
| 用户拒绝后再次打开 | 重新弹声明 |
| 声明版本升级 | 老用户重弹一次，重新同意 |
| 已登录用户升级 App | 仍先过门禁（版本升级且声明版本变才弹） |
