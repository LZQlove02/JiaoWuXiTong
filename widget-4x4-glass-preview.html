A · 全透明：课程块 = 液态玻璃

  • 左上 56% 白色高光斜扫 + 26%→9% 整体白 + 1px 亮描边 + 柔和外投影，中性无色相。
  • 九门课不再靠颜色区分，靠位置和课名 —— 这是“干净”的代价，也是液态玻璃的前提。
  • 真机落差：Android 位图没有背景模糊，只能用「半透明白 + 高光边 + 投影」近似，约八成；预览里的真实虚化到不了。

B / C · 不透明与液态玻璃：毛玻璃冷色（三档 × 40%，无边框）

  • 统一 opacity .40：块面 = 40% 冷色 + 60% 卡片底。白卡上三档落成 #D5E0EB / #B9CADD / #9DA9BD。
  • 色相只在 205–215°（蓝 → 石板蓝），只调明度分三档，不做绿/橙/红。
  • 三档统一深墨字 #12202C（对比 5.7–13:1）：40% 不透明度下最深的块也只能到 #9DA9BD，白字在上面只有 2.3:1，所以不再需要白字。
  • 无描边：只有 40% 填充 + 极轻投影，磨砂感靠半透明叠色与 8px 背景模糊。
  • 位图 ARGB_4444 的 alpha 只有 16 档，0.4 = 6/15 正好对齐，不会偏色。
