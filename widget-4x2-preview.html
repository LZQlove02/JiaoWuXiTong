4×2 今日课程 · 结构方案 B

时间 + 「课名 · 教室」两段式单行，右侧状态；空态居中、超额占位。按真机 300×140dp 还原，放大 1.5 倍展示。

壁纸
同一套结构，三种卡片底；状态只有「进行中 / 待上 / 已结束」三种

结构要点

  • 每条课一行：左侧时间固定 42dp，中间 课名 · 教室 单行省略，右侧 34dp 状态。
  • 截断优先级：先截教室 → 再截课名；不再像现在这样固定 108dp 给教室、先牺牲课名。
  • 进行中：左侧 3px 强调竖条 + 浅底 + 时间转强调色；已结束整行 44% 透明；待上不着色。
  • 空态：主体区垂直居中「今天没有课」，底部仍保留下一节，卡片不再「上半截有字、下半截空」。
  • 超额：第三行换成「还有 2 门 · 打开查看」，点击整卡进课表。

真机约束

  • 4×2 高度实测约 140dp：头部 22 + 底部 18 + 内边距 20，主体只剩约 62dp，所以每行 20dp、只放得下 3 行单行文本。
  • RemoteViews 不能 addView：仍是 3 个固定槽位，状态点/竖条用固定 View + 背景色，不用动态布局。
  • 「今日 · 周五」的星期由 payload.today[] 里任一条的 dayLabel 推；没有课就用 next.dayLabel；都没有则退回「今日课程」。

相对现状的变化

  • 去掉固定 108dp 的教室列（它现在挤得课名先被省略）。
  • 新增状态列，解决「不知道哪节正在上」。
  • 空态从「顶部一行 + 下方空白」改为居中，卡片不再显得坏掉。
  • 标题补星期，跨天刷新后一眼知道是哪天。
